# Evaluar una afirmación sobre Geoda

1. Escribe la afirmación concreta y qué observación la respaldaría. Identifica las dos versiones o condiciones, la fuente, el período, la unidad independiente y la regla de selección de la muestra.
2. Para el piloto de Site reproduce los números con `$revisar-calibracion-site`. Separa bloques, páginas con candidatos y páginas inéditas. En telemetría comprueba equipo, versión, escena, perfil, unidad y repeticiones antes de atribuir diferencias al motor.
3. Busca páginas usadas durante el ajuste, equipos repetidos, cambios de rúbrica, cambios de cobertura y revisores compartidos. Indica para cada uno la evidencia disponible y cómo podría cambiar la conclusión.
4. Presenta observación, incertidumbre, conclusión que permite la muestra y dato que falta para sostener una afirmación más amplia. Con un solo lote etiquetado admite una conclusión descriptiva. Para atribuir una mejora entre versiones identifica un conjunto de evaluación comparable.
5. En el ejemplo histórico de Site, 20/24 páginas inéditas dieron una muestra útil y el límite inferior unilateral al 95 % fue 67,6 %. El 64/70 describe bloques del censo. Comprueba los archivos si se usa otro piloto.
